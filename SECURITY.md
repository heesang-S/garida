# Security Policy

## Supported versions

Garida is pre-release software. Security fixes are made on the latest commit on
the default branch and, once published, the latest alpha release. Older alpha
releases may not receive fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Use [GitHub Security Advisories](https://github.com/heesang-S/garida/security/advisories/new)
to send a private report with:

- a description of the issue and its impact;
- affected package, version, and environment;
- steps or a proof of concept that reproduces it; and
- any suggested mitigation, if available.

The maintainers will acknowledge the report, assess its impact, and coordinate
a fix and disclosure. Please allow time for a response before disclosing the
issue publicly.

## Scope

Report vulnerabilities in this repository's source, release artifacts, and
documented local integrations. Provider accounts, third-party services, and
unpublished local configurations are outside this policy unless the issue is
caused by Garida itself.
