# Support

Use [GitHub Discussions](https://github.com/heesang-S/garida/discussions) for
usage questions, integration ideas, and general help. Use
[GitHub Issues](https://github.com/heesang-S/garida/issues) for reproducible
bugs and narrowly scoped feature requests.

Please include the Garida package and version, Node.js version, operating
system, and a minimal reproduction when reporting a problem. Do not include
API keys, access tokens, private prompts, or other sensitive data.

Security vulnerabilities belong in a private
[GitHub Security Advisory](https://github.com/heesang-S/garida/security/advisories/new).
